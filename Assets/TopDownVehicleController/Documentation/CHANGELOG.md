## Versioning Policy

This project follows **Semantic Versioning (SemVer)**.

Version format:

**MAJOR.MINOR.PATCH**

### MAJOR

Breaking changes.

Examples:

* API redesign.
* Architecture changes.
* Incompatible systems.

### MINOR

New features added without breaking compatibility.

Examples:

* New gameplay systems.
* New modules.
* New configuration options.
* Performance improvements.

### PATCH

Bug fixes and minor improvements.

Examples:

* Bug fixes.
* Documentation updates.
* Internal optimizations.
* Minor editor improvements.

---

## Supported Unity Versions

### Minimum Supported Version

Unity **2021.3.45f1 LTS**

### Officially Supported

Unity **2021.3.45f1 LTS** and newer.

### Earlier Versions

Unity versions earlier than **2021.3.45f1 LTS** are not officially supported, are not tested, and will not receive compatibility fixes or commercial support.

---

## Mandatory Dependencies

The following Unity packages are required:

* Input System
* Cinemachine

These packages are mandatory for all supported versions of the framework.
